## Notes & cautions

- The FaceX detector **engine source** (`include/detect.h` in facex-engine/facex) states **CC BY-NC-SA 4.0** — non-commercial + share-alike. The `sdk/*.wasm` engines are builds of that source lineage. If you use this project for a commercial event, either obtain written clearance from the FaceX author, replace the detector with a permissively licensed one (the FaceX ONNX FCOS detector is claimed Apache 2.0 but provides no keypoints for alignment), or treat this as an evaluation prototype.
- No biometric data is committed: the LFW dataset, roster folders, import JSON and embeddings stay local (`data/` is git-ignored).
- FaceX benchmark/evaluation results in `results/` are this project's measurements, not the FaceX author's claims.
